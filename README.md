# CS2 Map manager plugin for Dedicated CS2 server using CCS 
Plugin made to vote for change of map. <br>
needs 60% or more to want to rtv in order to start a vote.


## Requirements
CounterStrikeSharp: https://github.com/roflmuffin/counterstrikesharp <br>
You need CounterStrikeSharp dll with runtime within your dedicated server to use this plugin

## Installation
1. build it with dotnet build
2. copy it into the plugins folder

## Commands
1. !rtv (rock the vote)
2. !nominate (no args shows a menu, otherwise use second arg for map name)
3. Menus are navigated using !1-9
